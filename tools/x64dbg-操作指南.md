# x64dbg 操作指南 — 定位 ECS world 指针

## 当前状态
x64dbg 已启动并加载 `enshrouded.exe`（PID 1712），停在系统断点（ntdll）。

## 第一步：设置断点

在 x64dbg 反汇编窗口（CPU 标签页），按 **Ctrl+G** 或点击地址栏，依次输入以下地址，按 **F2** 下断点：

| 地址 | 作用 |
|---|---|
| `140955400` | SendEvent — 事件写入函数，看 rcx/edx/r8d/r9d |
| `1403E93AF` | HitEvent 发送调用点 |
| `14047D718` | TameWildlifeEvent 处理器 |

> 地址栏输入要用完整 VA（`140955400`），不要带 `0x` 前缀。

下断点成功后地址会变红色。

## 第二步：运行游戏

按 **F9**（或点"运行"按钮）让游戏继续。

游戏会启动到主菜单。**用 Steam 启动的那个游戏实例请先关掉**，避免冲突。

## 第三步：进入世界并触发事件

进游戏存档后：
1. **打一只狼**（任意武器）→ 会命中 `1403E93AF` 断点
2. 每次断点命中，x64dbg 会停下，右侧寄存器面板显示各寄存器值

## 第四步：记录关键寄存器值

断点命中时，请把**寄存器面板**的这些值记下来（或截图给我）：

### 在 `1403E93AF`（HitEvent 发送点）命中时：
```
RCX = ?    ← 事件缓冲区指针
RDX = ?    ← 应该是 0xCC0D57E0
R8  = ?    ← 应该是 0xF8
R9  = ?    ← 实体 ID
RAX = ?    ← 通常是缓冲区内指针
```

### 在 `140955400`（SendEvent）命中时：
```
RCX = ?    ← 事件缓冲结构
RDX = ?    ← 事件类型哈希
R8  = ?    ← 事件大小
R9  = ?    ← 实体 ID
```

## 第五步：追踪 ECS world

最关键的是 **RCX 指向的结构**。

在 x64dbg 底部**内存转储窗口**，输入 RCX 的值（比如 `0x000001D3...`），按回车查看内存。

我们要找的是：**从 RCX 出发，经过若干次解引用，能到达一个包含大量实体数据的结构**——那就是 ECS world。

具体操作：
1. 内存窗口输入 RCX 的值
2. 看前几行 qword，找一个**非零且不像栈地址**的指针
3. 双击它，跟随到新地址
4. 重复 2-3，直到看到一个结构里有很多重复模式的实体记录

## 需要你提供的信息

断点命中时，请告诉我：
1. **RCX / RDX / R8 / R9 / RAX 的值**
2. 内存窗口中 RCX 指向的**前 4-8 行 qword 值**

有这些我就能推出 ECS world 指针的位置。
